You can. Anything you do in the console can also be done from code, with the AWS <Term id="sdk" />. Under the hood, it calls the S3 <Term id="api" /> for you.

First, install the SDK: `npm install @aws-sdk/client-s3` for JavaScript or `pip install boto3` for Python. Then pick a language and see how to upload and list files.

<CodeTabs>
<Fragment slot="js">

```js title="upload.mjs"
import { readFile } from 'node:fs/promises';
import { PutObjectCommand, S3Client } from '@aws-sdk/client-s3';

const s3 = new S3Client({ region: 'us-east-1' });

await s3.send(
  new PutObjectCommand({
    Bucket: 'my-example-bucket',
    Key: 'photos/2026/beach.jpg',
    Body: await readFile('beach.jpg'),
  }),
);
```

</Fragment>
<Fragment slot="python">

```python title="upload.py"
import boto3

s3 = boto3.client('s3', region_name='us-east-1')

s3.upload_file('beach.jpg', 'my-example-bucket', 'photos/2026/beach.jpg')
```

</Fragment>
</CodeTabs>

<CodeTabs>
<Fragment slot="js">

```js title="list.mjs"
import { ListObjectsV2Command, S3Client } from '@aws-sdk/client-s3';

const s3 = new S3Client({ region: 'us-east-1' });

const { Contents = [] } = await s3.send(
  new ListObjectsV2Command({ Bucket: 'my-example-bucket', Prefix: 'photos/' }),
);

for (const object of Contents) console.log(object.Key, object.Size);
```

</Fragment>
<Fragment slot="python">

```python title="list.py"
import boto3

s3 = boto3.client('s3', region_name='us-east-1')

response = s3.list_objects_v2(Bucket='my-example-bucket', Prefix='photos/')

for obj in response.get('Contents', []):
    print(obj['Key'], obj['Size'])
```

</Fragment>
</CodeTabs>

Notice that no password shows up in the code. The SDK finds the credentials in the environment, such as environment variables or the AWS CLI configuration file.
