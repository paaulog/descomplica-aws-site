Amazon S3 is an **object storage** service in the cloud. You upload files and AWS takes care of the space, the backup copies and the access.

Each file becomes an <Term id="object" />, kept inside a <Term id="bucket" />. There is no disk to format and no server to turn on.

<CardGrid>
  <Card title="Space">
    You do not reserve a size. Store a 1 KB file or terabytes of video, and pay only for what you
    used.
  </Card>
  <Card title="Durability">
    Each object is copied to several devices, across at least three
    <Term id="availability-zone">Availability Zones</Term>. The designed
    <Term id="durability" /> is 99.999999999% per year.
  </Card>
  <Card title="Access">
    You read and write over the internet, from anywhere: through the console, the command line or
    your code.
  </Card>
  <Card title="No server">
    Nothing to install, update or restart. S3 is always on, waiting for your files.
  </Card>
</CardGrid>
