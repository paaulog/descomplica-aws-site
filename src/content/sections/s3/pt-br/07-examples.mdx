Não é coisa só de projeto pequeno. A própria AWS publica como empresas usam o S3, e cada exemplo abaixo traz a fonte.

<CardGrid>
  <Card
    title="Photobox"
    source="https://aws.amazon.com/s3/customers/"
    sourceLabel="Clientes do Amazon S3"
  >
    O serviço de álbuns e impressão de fotos migrou **10 petabytes** de fotos dos próprios
    servidores para o S3. São 10 milhões de GB.
  </Card>
  <Card
    title="Ryanair"
    source="https://aws.amazon.com/s3/customers/"
    sourceLabel="Clientes do Amazon S3"
  >
    A companhia aérea trocou os backups em fita pelo S3 Glacier e economizou **65%** no custo de
    backup.
  </Card>
  <Card
    title="Zalando"
    source="https://aws.amazon.com/s3/customers/"
    sourceLabel="Clientes do Amazon S3"
  >
    A loja de moda online guarda os dados para análise no S3 e economiza **37%** por ano com o S3
    Intelligent-Tiering.
  </Card>
  <Card
    title="Nasdaq"
    source="https://aws.amazon.com/s3/customers/"
    sourceLabel="Clientes do Amazon S3"
  >
    A bolsa de valores guarda dados críticos no S3 e no S3 Glacier.
  </Card>
</CardGrid>

Repare que são usos bem diferentes: fotos, backup e análise de dados. É o mesmo serviço, com as mesmas peças que você acabou de aprender.
