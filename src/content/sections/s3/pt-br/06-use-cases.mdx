Quase todo app que você usa guarda arquivos em algum lugar. Estes são os usos mais comuns do S3:

- **Arquivos de usuários:** fotos de perfil, anexos e documentos enviados num app.
- **Backups:** cópias do banco de dados ou dos computadores da empresa.
- **Sites estáticos:** o HTML, o CSS, o JavaScript e as imagens de um site.
- **Vídeos:** as aulas de uma plataforma de cursos, por exemplo.
- **Dados para análise:** logs e arquivos enormes que alimentam relatórios.

Repare num detalhe: o app não guarda a foto, só a chave dela. Quem guarda, copia e entrega o arquivo é o S3.
