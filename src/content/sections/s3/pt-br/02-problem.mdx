Imagine que o seu app guarda as fotos de perfil no disco do próprio servidor. Funciona bem no começo. Até o dia em que não funciona mais.

<CardGrid>
  <Card title="O disco enche">
    Cada usuário novo traz mais fotos. Um dia o espaço acaba, e o upload para de funcionar.
  </Card>
  <Card title="O disco quebra">
    Disco é peça que gasta. Se ele quebra e não tem cópia, as fotos vão junto.
  </Card>
  <Card title="O acesso explode">
    Quando o app faz sucesso, o mesmo servidor precisa entregar milhares de arquivos ao mesmo tempo.
  </Card>
  <Card title="E a conta?">
    Disco maior, servidor reserva, alguém para cuidar das cópias. Tudo isso custa, mesmo parado.
  </Card>
</CardGrid>

Talvez você esteja pensando: "é só comprar um disco maior". Funciona, até a próxima vez.
